The public site does not expose mailbox APIs. Mailbox APIs live in `apps/web`.

The only launch exception on the public site is the docs search route used by the static Fumadocs/Orama search flow.

## Product app groups

- `/api/accounts/*` handles Google connection state and permission upgrades.
- `/api/mail/*` handles mailbox metadata, labels, sync, activity, filters, and actions.
- `/api/ai/*` handles AI suggestions, summaries, task extraction, replies, and application of accepted suggestions.
- `/api/settings/*` handles AI and privacy settings.

## Response envelope

Launch-critical product routes now use a shared envelope shape:

```ts
type ApiSuccess<T> = {
  ok: true;
  data: T;
  meta?: Record<string, unknown>;
};

type ApiFailure = {
  ok: false;
  error: {
    code: string;
    message: string;
    details?: unknown;
  };
  meta?: Record<string, unknown>;
};
```

## Error notes

- Unauthorized requests return a stable `ApiFailure`.
- Permission-upgrade requirements return structured product errors instead of ad hoc payloads.
- Pro-unavailable optional-extension routes use `402` with the shared failure envelope.

Demo mode lets these APIs run against deterministic local fixtures without a signed-in session.
