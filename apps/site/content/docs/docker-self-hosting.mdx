---
title: Docker self-hosting
description: Track the Docker-first deployment path for the OSS launch.
---

Docker-first deployment templates are planned for launch readiness. Until those templates land, the supported path is local development with pnpm and the app-level environment file.

## Expected template goals

- Product app container.
- Database profile selection.
- Public site container or static public site build.
- Environment examples for Better Auth and Google OAuth.
- Smoke commands for auth, mail list, demo mode, and public docs.

Docker templates will not turn InboxCtrl into a hosted SaaS. You remain responsible for credentials, database storage, backups, and infrastructure.
