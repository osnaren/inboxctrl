title: Local setup
description: Run the self-hosted product app from a checkout.
---

## Prerequisites

- Node and pnpm matching the repo package manager.
- A local database profile. SQLite is the default development path.
- Google OAuth credentials for real Gmail access.

## Commands

```bash
pnpm install
pnpm db:generate
pnpm db:push
pnpm dev
```

The product app runs from `apps/web`. The shared Prisma schema lives in `packages/db/prisma/schema.prisma`. The public site is separate and runs with `pnpm dev:site`.

## Environment

Copy the matching example file to `apps/web/.env`:

- `apps/web/.env.example.sqlite` for local SQLite development
- `apps/web/.env.example.postgres` for Postgres-backed self-hosting
- `apps/web/.env.example.demo` for local demo mode

`apps/web/.env.example` remains the generic baseline if you want a single template.

Keep `INBOXCTRL_DEMO_MODE=false` when connecting a real mailbox.
